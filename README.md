# AkSeC

AkSeC, siber güvenlik görünürlüğü ve bulgu yönetimi üzerine hazırlanmış bir **ürün konsepti** sitesidir. Gerçek müşteri, ekip, tamamlanmış ürün veya başvuru uygunluğu iddiası içermez.

## Konsept

Planlanan akış; yetkili varlıkları listelemeyi, güvenlik bulgularını bağlamıyla değerlendirmeyi ve düzeltme adımlarını izlemeyi hedefler. Sitedeki panel ve sayılar temsili örneklerdir.

## Site

[index.html](index.html) dosyası bağımsız bir statik sayfadır. Dış bağımlılık gerektirmez ve GitHub Pages üzerinden yayımlanır.
